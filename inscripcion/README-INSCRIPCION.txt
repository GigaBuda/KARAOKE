PROYECTO DE INSCRIPCIÓN KARAOKE
- Code.gs: servidor de Apps Script.
- Index.html: formulario web.
- Lee cantante/autor de la columna B y canción de la columna D.
- Guarda las inscripciones en "Inscripciones Karaoke".

INSTALACIÓN
1. Abre https://script.google.com/ y crea un proyecto.
2. Copia Code.gs en el editor de script.
3. Añade un archivo HTML llamado Index y copia Index.html.
4. Guarda y ejecuta getCatalog para autorizar el acceso a la hoja.
5. Implementar > Nueva implementación > Aplicación web.
6. Configura para ejecutar como tú y permite el acceso que necesiten los participantes.
7. Comparte la URL /exec del formulario.

Nota: este formulario usa Google Apps Script (google.script.run), no se despliega directamente en Vercel como un HTML estático.
