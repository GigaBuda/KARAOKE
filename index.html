Conectar Google Sheets

Publica el script de Google Apps Script incluido en el ZIP y pega aquí la URL de la aplicación web que termina en /exec.

Para que la conexión funcione, el script debe estar implementado como aplicación web y tener acceso autorizado a la hoja. La primera comprobación carga la lista sin avisar de inscripciones antiguas.
